## 0. 口径与方法声明（先读）

1. **行号基准**：全部为 V1.2 实际行号（`read` 逐行核对 + 标题行号提取，非估算）。§A 的"起止行"＝标题所在行 至 下一个同级/更高级标题前一行（含分隔线 `---`）。
2. **两种"已实现"必须分开**：
   - **Skill 侧已跑通**：Skill v1.4.1 的解析规则/数据口径在真实病历上验证通过（版本记录）；
   - **App/服务端已实现**：本仓库代码里确有对应实体/接口/界面。本次只做**抽样代码核对**（见 §0.1），最终判断仍以 PRD 文本 vs Skill 规范为准。
3. **Skill 依据的标注**：本地仓库没有 Skill v1.4.1 源文件，版本记录条目以任务下发的 Skill 能力清单与上一轮分享链接引用为准：
   - `【S1.1.0】`＝Skill 版本记录 1.1.0 模块扩展条目（症状日记/用药监测/内镜影像/就诊住院急诊/营养/疫苗/心理/预警与待办/待核对队列/schema/备份，见上一轮分析 L79 reference:14）；
   - `【S1.4.0】`＝Skill 版本记录 1.4.0 检查 PDF 解析与检验解析修复项（见上一轮分析 L4/L39 reference:3-5）；
   - `【S1.4.1】`＝本次任务下发的 Skill v1.4.1 能力清单，按条目名引用（如"检验解析-日期优先级"）；
   - 无法逐字核对的条目在依据列写 `版本号待核`，不臆造版本号。
4. **状态三态**：仍存在 / 已修正 / 需细化。V1.2 的 `V1.1→V1.2 修订清单`（L1045–1058）只覆盖 P0 批次 T1–T7，**上一轮 9 条均不在该批次内**，这是本轮 9 条几乎全数"仍存在"的直接原因。

16. **C-29 全局产品边界**：新增章节固化"只记录/提醒/趋势描述；不诊断、不建议、不改医嘱"，并清理 L487–488 的建议口吻。
