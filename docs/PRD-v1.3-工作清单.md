## 0. 使用规则

### 0.1 状态与登记

| 字段 | 规则 |
|---|---|
| 状态 | 全表初始 `待办`；开工改 `进行中`、完成改 `已完成`、受阻改 `阻塞` 并写原因。状态必须**同时**回写 `session-worklist.md`，只改面板不改清单＝未完成 |
| 登记 | 每个 V13 ID 已在 `session-worklist.md` 新增 **P8.5「PRD v1.3 对齐」**段逐行登记（2026-11-02），验收标准引用本表同名行 |
| 关闭 | 关闭前须满足附 B 全部 DoD；无证据不得关；无法验证的标 `阻塞` 并写解除条件 |

### 0.2 优先级

| 级别 | 定义 |
|---|---|
| P0 | 不做则 v1.3 不成立，或触碰合规红线（医学口径错、诊断/建议越界、数据模型阻塞后续批次） |
| P1 | 影响数据质量或口径一致性，应进 v1.3，可与 P0 分两步落地 |
| P2 | 工程规范/文档完备性，可后置到 v1.4 |

### 0.3 工作量（粗估，单人日）

S ≤ 0.5 天（口径/文案/单字段）｜M 1–2 天（模型/单模块）｜L 3–5 天（跨端改造/迁移+端到端验收）。

### 0.4 批次顺序（严格串行）

批0 文档与口径 → 批1 数据模型与指标字典（**阻塞批2/3/4**）→ 批2 解析能力 → 批3 模块补全 → 批4 规则与呈现。
